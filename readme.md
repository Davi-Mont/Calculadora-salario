# Calculadora de Salário (Calculadora-salario)

Uma pequena aplicação front-end em HTML/CSS/JavaScript para calcular reajuste salarial, férias e décimo terceiro com base em valores informados pelo usuário. O projeto está em Português e foi criado como exercício/pequena ferramenta interativa.

## Funcionalidades
- Calcular novo salário com base em faixa de aumento (15%, 10% ou 5%).
- Calcular valor das férias (salário + 1/2).
- Calcular décimo terceiro proporcional (salário * meses / 12).
- Interface simples em HTML com estilos básicos em CSS.
- Dois scripts JavaScript no repositório (duas abordagens diferentes para o menu/fluxo).
